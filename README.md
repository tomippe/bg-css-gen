# BG CSS Gen

画像から CSS の `background` 指定を視覚的に組み立てる Web ツールです（Vue 3 + Vite）。apps.tomippe.jp で公開: https://apps.tomippe.jp/bg-css-gen/

## 開発

```bash
npm install
npm run dev
```

## ビルド

```bash
./build.sh
```
